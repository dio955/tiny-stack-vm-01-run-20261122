# Tiny stack VM

An exact interpreter of make.fun's tiny stack ISA v1: 32-bit wrapping integers, a 256-value stack, branches, calls, 256 words of memory, input/output, ten traps, and step/output limits. One run answers every instance in `MAKEFUN_INPUT_DIR`, writing `<id>/stdout.bin` and `<id>/exit.txt` under `MAKEFUN_OUTPUT_DIR`. Run it with `node main.ts`.

Entry for the [tiny-stack-vm-01 bounty on make.fun](https://make.fun/bounty/tiny-stack-vm-01-run-20261122).
